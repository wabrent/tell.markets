06 / x402

No account. Just pay.

Full checks past the free allowance answer 402 Payment Required with x402 requirements: scheme exact, network eip155:4663, asset USDG 0x5fc5…d168 (6 decimals). Your agent signs an EIP-3009 TransferWithAuthorization and retries with the X-PAYMENT header. Tell verifies it, runs the check, submits the transfer on-chain (Tell pays the gas) and returns the result with X-PAYMENT-RESPONSE holding the tx hash. If the check fails, nothing is charged.

import { privateKeyToAccount } from 'viem/accounts';
const account = privateKeyToAccount(process.env.AGENT_KEY);  // holds USDG, needs no ETH
const url = 'https://tell.markets/api/v1/check?token=0x…&mode=full';

let res = await fetch(url);
if (res.status === 402) {
  const { accepts: [req] } = await res.json();
  const auth = {
    from: account.address, to: req.payTo, value: req.maxAmountRequired,
    validAfter: '0', validBefore: String(Math.floor(Date.now() / 1000) + 120),
    nonce: '0x' + [...crypto.getRandomValues(new Uint8Array(32))].map(b => b.toString(16).padStart(2, '0')).join(''),
  };
  const signature = await account.signTypedData({
    domain: { name: req.extra.name, version: req.extra.version, chainId: 4663, verifyingContract: req.asset },
    types: { TransferWithAuthorization: [
      { name: 'from', type: 'address' }, { name: 'to', type: 'address' }, { name: 'value', type: 'uint256' },
      { name: 'validAfter', type: 'uint256' }, { name: 'validBefore', type: 'uint256' }, { name: 'nonce', type: 'bytes32' } ] },
    primaryType: 'TransferWithAuthorization',
    message: { ...auth, value: BigInt(auth.value), validAfter: 0n, validBefore: BigInt(auth.validBefore) },
  });
  const payment = btoa(JSON.stringify({ x402Version: 1, scheme: 'exact', network: req.network, payload: { signature, authorization: auth } }));
  res = await fetch(url, { headers: { 'X-PAYMENT': payment } });
}
const report = await res.json();

Any x402 client library that supports EVM exact works the same way.

07 / API keys

Hold $TELL, check for free.

Sign in with your wallet (top right), create a key and send it as Authorization: Bearer tell_… to the API or MCP. While the wallet holds enough $TELL, full checks through the key are free. Keys are optional: without one, the free allowance and x402 apply.


      

    


    

      08 / Proof
      
Scores you can verify.

      
Every finished check becomes a leaf keccak256(abi.encode(token, score, keccak(verdict), keccak(checks), checkedAtMs)). Each hour the leaves are folded into a Merkle root (pairs hashed sorted) and the root is written to Robinhood Chain as the data of a transaction: 0x54454c4c ("TELL") followed by the root. /api/v1/proof/0x… returns each verdict with its proof. Ledger, roots, payments and burns: tell.markets/proof.
